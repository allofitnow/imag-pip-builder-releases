# IMAG Pip Builder releases

This public repository contains signed IMAG Pip Builder installers and the update manifest only. Application source is maintained separately in a private repository.

Download a published release for Windows x64 or macOS Apple Silicon from Releases. After installing an update-enabled version, use Check for updates inside the app for subsequent signed releases.

The updater verifies installer signatures. This repository must never contain source archives, private signing keys, access tokens, or project/media files.
